Политика конфиденциальности

Последнее обновление: 12 сентября 2026

Настоящая Политика конфиденциальности описывает, какие данные собирает приложение Foxint AI (далее — «Приложение»), как они используются и защищаются. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

1. Разработчик

Приложение разработано и поддерживается redantonov (далее — «Разработчик»).

  • Контакт для связи: @redantonov в Telegram
  • Telegram-канал: @foxintai

2. Какие данные мы собираем

Приложение собирает минимально необходимый объём данных:

  • Email и пароль — при регистрации. Пароль хранится в зашифрованном виде. Email используется для входа и восстановления доступа.
  • История чатов — сообщения, которые вы отправляете AI-ассистенту, сохраняются для синхронизации между устройствами.
  • Технические данные — сведения об устройстве и ошибках, если они возникают.

Приложение не запрашивает: доступ к контактам, SMS, геолокации устройства, камере, микрофону (кроме момента использования голосового ввода по вашему нажатию), файловой системе за пределами явно выбранных вами файлов.

3. Как мы используем данные

  • Для аутентификации и предоставления доступа к Приложению
  • Для синхронизации истории чатов между вашими устройствами
  • Для обработки запросов к AI-ассистенту и OSINT-функциям
  • Для связи с вами по вопросам работы Приложения

4. Где хранятся данные

Данные пользователей хранятся на серверах Supabase (регион Frankfurt, ЕС), защищённых шифрованием в покое и при передаче (TLS).

Запросы к AI-ассистенту и OSINT-функциям обрабатываются через прокси-сервер на Render и передаются в сервисы:

  • GigaChat (Сбер) — для генерации ответов AI
  • Публичные API для геолокации IP, DNS и проверки утечек

Мы не продаём и не передаём ваши данные третьим лицам, кроме случаев, необходимых для работы Приложения (перечислены выше).

5. OSINT-функции

Приложение предоставляет инструменты для анализа открытых источников:

  • .u ник — поиск username на публичных платформах
  • .i ip — геолокация IP-адреса
  • .e email — проверка email и MX-записей
  • .d domain — DNS-разбор домена
  • .b email — проверка email в публичных базах утечек

Все данные берутся из публично доступных источников. Приложение не осуществляет взлом, не использует закрытые базы данных и не хранит персональные данные третьих лиц.

6. Файлы

Пользователь может прикрепить к чату текстовые файлы (.txt, .md, .json, .js, .py и другие). Файлы обрабатываются локально на устройстве и передаются в AI-модель только для обработки вашего запроса. Содержимое файлов не хранится на серверах Разработчика дольше, чем это необходимо для ответа.

Приложение не принимает изображения, видео, аудио и бинарные форматы.

7. Файлы cookie и локальное хранилище

Приложение использует localStorage вашего браузера или устройства для:

  • Сохранения сессии авторизации
  • Хранения настроек (тема, шрифт, режим)
  • Черновика сообщения и локальной копии чатов

Эти данные хранятся только на вашем устройстве и не передаются автоматически.

8. Права пользователя

Вы имеете право:

  • Запросить копию своих данных
  • Удалить свой аккаунт и все связанные данные
  • Исправлять неточности в данных
  • Отозвать согласие на обработку данных

Для реализации этих прав свяжитесь с Разработчиком: @redantonov.

Кнопка «Удалить всё» в настройках Приложения немедленно удаляет все локальные данные с вашего устройства.

9. Безопасность

Мы применяем следующие меры защиты:

  • Пароли хешируются алгоритмом bcrypt (стандарт Supabase Auth)
  • Соединение защищено HTTPS/TLS 1.3
  • Row Level Security в базе данных — каждый пользователь видит только свои данные
  • Токены авторизации обновляются автоматически

10. Дети

Приложение не предназначено для детей младше 13 лет. Если вы родитель и считаете, что ваш ребёнок предоставил нам личные данные без вашего согласия, свяжитесь с Разработчиком — мы удалим их.

11. Изменения политики

Разработчик может обновлять настоящую Политику. Актуальная версия всегда доступна по адресу /privacy.html. Дата последнего обновления указана в начале документа.
